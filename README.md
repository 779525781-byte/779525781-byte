## 🧭 工作主线

1. **内容生产**：抖音信息流视频剪辑（部门主责）+ 淘宝/天猫首图视频（辅助）
   - 儿童线：实拍模特素材 + 静物素材 → 混剪
   - 成人线：AI 模特素材 + 静物素材为主
2. **素材基建**：模特 / 静物素材自动打标与批量重命名（星级评分卡、可回滚）
3. **千川登记**：优质视频月度登记到金山文档多维表格，按店铺分表
4. **绩效核算**：月度视频绩效得分（6 类全计入 + 双层模型，4 人排名）
5. **汇报输出**：周报 / 月度一图（HTML → 16:9 高清 PNG）
